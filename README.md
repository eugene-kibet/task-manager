# 📝 Personal Task Manager

A responsive, interactive task management web application built with vanilla HTML, CSS, and modern JavaScript. Tasks and completion states persist directly in the browser using `localStorage`.

## 🚀 Live Demo
[https://task-manager-mu-mocha.vercel.app](https://task-manager-mu-mocha.vercel.app)

---

## ✨ Features
- **Task Management:** Add, edit, and delete individual tasks.
- **Bulk Actions:** Clear all tasks with confirmation handling.
- **Completion Tracking:** Toggle completed states with dynamic strikethrough styling.
- **Dynamic Dashboard:** Real-time completion counter and visual progress bar.
- **Motivational Feedback:** Contextual messages that adapt to task progress.
- **Data Persistence:** Tasks and statuses persist across page reloads via `localStorage`.
- **Keyboard Shortcuts:** Press `Enter` in the input field to create tasks quickly.

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Vercel** (Automated Continuous Deployment)

## 💻 Running Locally

1. Clone the repository:
  ```bash
   git clone [https://github.com/eugene-kibet/task-manager.git](https://github.com/eugene-kibet/task-manager.git)
   ```
2. Navigate into the folder:
   ```bash
   cd task-manager
   ```
3. Open `index.html` in your web browser.
